# Contesto
Sono uno studente di web design.

## Regole e vincoli del progetto
- **Spiegazione prima del codice:** spiega sempre il ragionamento prima di proporre codice; non riscrivere interamente i miei file.
- **Tecnologie consentite:** usa solo HTML e CSS; niente JavaScript e niente framework.
- **Stili e variabili:** colori e caratteri sono definiti come custom property in `:root`; usa sempre quelle.
- **Scala delle misure:** usa esclusivamente valori provenienti dalla scala `8, 16, 24, 32, 48, 64 px`, convertiti in `rem`.
- **Chiarezza sulle modifiche:** per ogni modifica suggerita, indica sempre in quale file va inserita e perché.
- **Struttura delle cartelle:**
  - Tutte le regole CSS devono stare in un unico file CSS dentro la cartella `css/`.
  - Tutte le immagini devono stare nella cartella `img/`.
